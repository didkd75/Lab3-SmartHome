# SmartHomeApp — Laboratory Work #3

Консольний додаток на C# (.NET 10), що моделює систему **«Інтелектуальний розумний дім»**.  
Проєкт виконано в рамках лабораторної роботи №3 з дисципліни **«Об'єктно-орієнтоване програмування»** на тему **«Конструктори. Перевантаження (Overloading)»**.

## 📌 Що реалізовано в Lab-3
- **Перевантажені конструктори (`Constructors Overloading`):**
  У класі `SmartDevice` реалізовано 4 конструктори з використанням ланцюгового виклику (`: this(...)`):
  1. `SmartDevice()` — конструктор без параметрів (ініціалізує об'єкт значеннями за замовчуванням).
  2. `SmartDevice(string serialNumber, string deviceName)` — конструктор з 2 параметрами.
  3. `SmartDevice(string serialNumber, string deviceName, DeviceType type, double powerUsage)` — конструктор з 4 параметрами.
  4. `SmartDevice(string serialNumber, string deviceName, DeviceType type, double powerUsage, bool isActive)` — головний конструктор з 5 параметрами.
- **Перевантаження методів (`Method Overloading`):**
  Реалізовано 3 версії методу `CalibratePower` із різними сигнатурами:
  - `CalibratePower(double newUsage)` — точне встановлення споживаної потужності у Вт.
  - `CalibratePower(double delta, bool isPercentage)` — коригування потужності на фіксовану дельту або у відсотках.
  - `CalibratePower()` — скидання потужності до базового заводського значення відповідно до типу пристрою.
- **Інкапсуляція та валідація:** Усі поля закриті (`private`), доступ реалізовано через властивості з генерацією виключень при некоректних значеннях та їх обробкою в `Program.cs` через `try-catch`.
- **Інтерактивне консольне меню:** Вибір конструктора під час створення об'єкта, перегляд у вигляді таблиці, пошук за характеристиками, демонстрація всіх перевантажень методу поведінки та видалення об'єктів.

## 🛠️ Структура проєкту
* `DeviceType.cs` — перелік (`enum`) типів пристроїв розумного дому (`Thermostat`, `SmartLight`, `SecurityCamera`, `SmartLock`).
* `SmartDevice.cs` — основний клас моделі пристрою з властивостями, конструкторами та перевантаженими методами.
* `Program.cs` — точка входу, консольний інтерфейс користувача, валідація введення та обробка виключень.
